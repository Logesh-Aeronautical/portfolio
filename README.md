# 🚀 Logesh - Aeronautical & Embedded Systems Portfolio

Welcome to the personal engineering portfolio of **Logesh**, specializing in **Aeronautical Engineering**, **Supersonic Aircraft Conceptual Design**, and **IoT / Embedded Systems**.

---

## 📌 Features

- **Flagship Aircraft Project: Project Interceptor**
  - Conceptual design of a Mach 2.1+ supersonic high-altitude interceptor.
  - Complete airframe specifications: MTOW (16,674 kg), Wing Loading, Thrust-to-Weight (1.79), L/D ratio (12.0), Wing Sweep (45°), etc.
  - Interactive **Operational Mission Profile** (High-Low-High Interception Envelope) tracing mission nodes 0 through 6.
- **Parametric Aeronautical Study (18 Comparative Plots)**
  - 18 high-resolution comparative engineering plots generated with Python (Pandas, Matplotlib, Seaborn).
  - Categorized into Weight Fractions, Geometry & Sizing, Propulsion & Thrust, and Aerodynamics.
  - Interactive inspection modal with technical insight and full-res download.
- **IoT & Embedded Systems Showcase (8 Internship Projects)**
  - Completed during internship at **Tamizan Skills**.
  - Implemented using **Arduino Uno**, **ESP32**, **Wokwi Simulator**, **Embedded C++**, and **Python (OpenCV/MediaPipe)**.
  - Covers Smart Water Level Indicator, IoT Agriculture, Smart Relays, Fire & Gas Safety, Smart Parking, Biometric CV Access, Health & Fall Monitor, and Smart Waste Management.
  - Direct links to source code on [Tamizan_Skills GitHub](https://github.com/Logesh-Aeronautical/Tamizan_Skills).
- **Interactive UI & Dark Aerospace Aesthetic**
  - Futuristic obsidian & electric cyan theme with glassmorphism cards and radar glow effects.
  - Responsive design across desktop, tablet, and mobile.
  - Zero build step required — runs out-of-the-box in any browser and deploys seamlessly to GitHub Pages.

## 🌐 Deploy to GitHub Pages

To make this portfolio live for free using GitHub Pages:

1. Create a repository on your GitHub account (`Logesh-Aeronautical`), for example named `portfolio` or `Logesh-Aeronautical.github.io`.
2. Push this repository:
   ```bash
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` and `/ (root)` folder, then click **Save**.
5. Your portfolio will be live at:
   - If repo name is `Logesh-Aeronautical.github.io`: `https://logesh-aeronautical.github.io/`
   - If repo name is `portfolio`: `https://logesh-aeronautical.github.io/portfolio/`
